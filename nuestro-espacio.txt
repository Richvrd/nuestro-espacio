# NUESTRO ESPACIO — Proyecto completo

Web app privada de pareja (Sarai ♥ Ricardo). Todo el UI en español.
Creada con Next.js 16.2.6 + React 19.2.4 + Supabase + CSS personalizado + Tailwind v4 (no usado en templates).

---

## 1. IDEA GENERAL

Aplicación web privada para una pareja, con:
- **Galería de fotos/álbumes** — subir fotos, crear álbumes, lightbox
- **Cartas de amor** — escribir, leer, editar, eliminar cartas
- **Lista de reproducción musical** — compartir canciones (scaffold)
- **Juego de memoria** — juego de parejas con temática propia (scaffold)
- **Cápsula del tiempo** — mensajes sellados hasta una fecha futura (scaffold)
- **Contador de tiempo juntos** — años:meses:días · horas:min:seg desde el inicio de la relación

Autenticación con Supabase (email + OAuth). Diseño dark-mode con paleta dorada/rosada.

## 5. MÓDULO GALERÍA (completo)

### 5.1 types.ts

```typescript
export interface Photo {
  id: string; url: string | null; title: string; caption: string;
  date: string; uploaded_by: string; album_id: string | null;
  created_at: string; emoji?: string; bg_gradient?: string;
}
export interface Album {
  id: string; title: string; caption: string; created_at: string;
  photos: Photo[];
}
export type GaleriaItem =
  | { type: 'photo'; data: Photo }
  | { type: 'album'; data: Album };
```

### 5.2 actions.ts (server actions)

- `getGaleriaItems()` → Promise<GaleriaItem[]> — fetches photos (sin album_id) + albums (con sus photos).
- `insertPhoto(url, title, caption)` → inserta foto en Supabase.
- `insertAlbum(title, caption, photoUrls)` → crea album + fotos en transacción.
- `updatePhoto(id, title, caption)` → update.
- `updateAlbum(id, title, caption)` → update.
- `deletePhoto(id)` → elimina de Storage + DB; si album queda vacío lo borra automáticamente.
- `deleteAlbum(id)` → elimina album + todas sus fotos (Storage + DB).

### 5.3 useFotos.ts (hook)

Estado: `{ items: GaleriaItem[], loading, uploading }`

- `uploadFoto(file, title, caption)` → comprime con compressImage, sube a Supabase Storage, inserta DB, refresh.
- `uploadAlbum(title, caption, files)` → comprime todas (quality 0.78), sube en paralelo, crea album + fotos, refresh.
- `editFoto(id, title, caption)` / `editAlbum(id, title, caption)` → optimista + server action.
- `deleteFoto(id)` / `deleteAlbum(id)` → optimista + server action.
- `refresh()` → refetch getGaleriaItems().

### 5.4 Componentes

| Componente | Props | Función |
|-----------|-------|---------|
| GaleriaGrid | items, onRefresh | Grid principal con modales y UploadModal |
| FotoCard | photo, onClick | Thumbnail con overlay, placeholder emoji+gradient |
| AlbumCard | album, onClick | Stack visual con primeras 2 fotos |
| FotoModal | photo, onClose, onEdit, onDelete | Modal detalle con sidebar, tres-puntos, edición inline |
| AlbumModal | album, onClose, onEdit, onDelete | Grid de fotos + expand view + editar/eliminar |
| UploadModal | onClose, onUpload | Wizard: seleccionar modo (foto/álbum) + formulario + drop files |
| Lightbox | photos, index, onClose | Fullscreen con prev/next, teclado (Escape, flechas) |

## 6. MÓDULO CARTAS (completo)

### 6.1 types.ts

```typescript
export interface Letter {
  id: string; from_name: string; to_name: string;
  subject: string; body: string; unread: boolean | null;
  created_at: string;
}
```

### 6.2 actions.ts (server actions)

- `getLetters()` → Promise<Letter[]> — todas ordenadas por created_at DESC.
- `insertLetter(from_name, to_name, subject, body)` → insert + `.select().single()` (retorna la letter).
- `updateLetter(id, subject, body)` → update + `.select().single()`.
- `deleteLetter(id)` → delete por id.

Todas llaman `revalidatePath('/cartas')`.

### 6.3 Componentes

| Componente | Props | Función |
|-----------|-------|---------|
| CartasApp | initialLetters | Grid + empty state + modales + estado local optimista |
| LetterReaderModal | letter, onClose, onEdit, onDelete | Modal con contenido + menú tres-puntos (editar/eliminar) |
| WriteLetterModal | onClose, onSaved, editLetter? | Modal formulario crear/editar: Para (select), Asunto (input), Carta (textarea) |

**CartasApp** mantiene estado local de letters (useState). Operaciones optimistas:
- Al crear: insertLetter → respuesta con letter → setLetters([newLetter, ...letters])
- Al eliminar: setLetters optimista + deleteLetter en servidor
- Al editar: abre WriteLetterModal en modo edición

**WriteLetterModal**:
- Select "Para" con opciones Sarai / Ricardo (de COUPLE.name1/name2)
- Input "Asunto" 100% width
- Textarea "Carta" 100% width, min-height 250px
- Botones: Cancelar / Enviar (o Guardar si edición)
- Layout: .form-group > label + .form-value > input/select, .write-form-divider (hr gradiente)

**LetterReaderModal**:
- Subject grande serif gold

- Botón tres-puntos (⋮) abre menú flotante .letter-menu-below con Editar/Eliminar

## 7. MÓDULO INICIO (componentes sueltos)

### 7.1 HeroCounter.tsx (cliente)

Hook `useCounter()` retorna años/meses/semanas/días/horas/min/seg desde COUPLE.startDate. Se actualiza cada 1s.

Display:
- Línea 1: años : meses : días (grande, gold, serif)
- Línea 2: horas : min : seg (pequeño, opaco)
- Línea 3: fecha de inicio formateada en Chile timezone

Los días mostrados son `weeks * 7 + days` (total días después de meses).

### 7.2 OrbitCanvas.tsx (cliente)

Canvas animado con requestAnimationFrame:
- 3 elipses orbitales concéntricas (rx=ry=Math.min(W,H)*0.2 → círculos perfectos)
- 2 estrellas orbitando (una gold #c9a96e, una rose #b8756a) con estela y glow radial
- Punto central con glow y pulso

### 7.3 CounterDisplay.tsx (cliente)

Versión Card del contador con años·meses·semanas·días·horas·min·seg (no se usa actualmente en página de inicio).

### 7.4 StatCard.tsx

Card simple: icono + valor grande (serif) + label (mono).

### 7.5 WishButton.tsx

Botón "te amo" con corazón animado (wave) y contador de wishes. Muestra "yo también..." feedback.

### 8.2 StarField

Canvas con estrellas: posición aleatoria, tamaño (1-3px), opacidad (0.3-0.9), duplicación (2-7s), delay (-20s a 0). `@keyframes tw` con opacidad variable.

### 8.3 ShootingStars

3 cadenas setTimeout independientes (desincronizadas). Cada ~1.5-5s lanza una estrella:
- `--len`: 80-220px (largo)
- `--angle`: -10° a -30°
- `--dur`: 1.0-1.8s
- `--y`: 0-100% (toda la pantalla, z-index 1)
La estrella se elimina del DOM tras 2200ms.

### 8.4 ToastProvider + useToast

Sistema de notificaciones. Provider envuelve app. useToast() retorna showToast(message, type). No hay toasts implementados en los módulos actuales.

### 8.5 ThemeToggle

Cambia clase `.light-mode` en body. Guarda preferencia en localStorage('theme').

### 8.6 EmptyState

Props: icon, title, subtitle. Centrado con icon grande + título serif + subtítulo muted.

## 15. PATRONES DE CÓDIGO

- **Server Actions**: cada módulo con CRUD (`'use server'`), usa `createClient()` de supabase/server, llama `revalidatePath()`.
- **Client Components**: `'use client'` para interactividad, hooks, modales.
- **Estado local**: useState + Server Actions con revalidación; operaciones optimistas con rollback en error.
- **Modales**: backdrop fijo + box centrado + botón X. Escape cierra, backdrop NO cierra (a menos que se especifique).
- **Body scroll lock**: cuando un modal está abierto.
- **Modularización por módulos**: cada feature en `modules/<name>/` con types, actions, components, hooks.
