La página de inicio es la primera vista al entrar a la aplicación
(después del login). Muestra un hero de bienvenida a pantalla completa
con una animación orbital y un contador del tiempo juntos, seguido de
secciones de contenido que revelan suavemente al hacer scroll por
primera vez.

2.1. MECÁNICA DE REVELADO (useScrollReveal)
────────────────────────────────────────────
  Archivo: hooks/useScrollReveal.ts

  - Escucha el evento 'scroll' en el elemento #main (el contenedor
    scrollable del layout).
  - Calcula un progreso de 0 a 1: scrollTop / (scrollHeight - clientHeight - 80).
  - Usa requestAnimationFrame para throttling.
  - Cada sección tiene un offset escalonado (idx * 0.14), de modo que
    aparecen una tras otra en lugar de todas a la vez.
  - Aplica opacity y translateY con easing cúbico (1 - (1-t)^3).
  - Cuando el progreso llega a 1, se marca "done = true" y se elimina
    el event listener. A partir de ahí el scroll es normal y todas las
    secciones quedan completamente visibles.
  - En cada refresco de página (navegación a /inicio), el efecto
    se reinicia porque el hook se monta de nuevo.

  Retorna: { progress, done, styleFor }
    styleFor(idx) → React.CSSProperties con opacity y transform.

2.2. COMPONENTE InicioSections
───────────────────────────────
  Archivo: app/(app)/inicio/InicioSections.tsx

  Render Prop: recibe un array de secciones { ornament, message, content }.
  Itera con .map() aplicando styleFor(i) a cada <section>.
  Cada sección tiene dos columnas (grid 1fr 2fr):
    .is-message → ornamental + frase poética (serif, itálica, muted)
    .is-content → el contenido dinámico de cada sección
